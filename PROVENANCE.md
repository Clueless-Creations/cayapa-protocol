# Publication provenance

Clueless Creations published this standalone Cayapa protocol bundle on November 21, 2026. The initial snapshot was extracted from the protocol directory at upstream revision `b3dc6c18d26e311c8899d0e7e74c2ed0dc7c58eb`. Only publication-facing documentation and the manifest changed for the split. The wire contracts, schemas, vectors, conformance runners and evidence are unchanged.

This repository does not contain the hosted application, server or client implementations, SDKs, connector implementations, deployment configuration or upstream repository history. Binding documents describe interoperable contracts; they do not ship the corresponding software.

The included reports record historical local or isolated evidence, not independent external adoption, a production deployment or a live cross-host test. See the [conformance instructions](conformance/README.md) to test an implementation and run `python3 check.py` to verify the distribution. The bundle has no open-source license or contributor terms at initial publication.
